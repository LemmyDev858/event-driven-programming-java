## Learning Outcome 2: Implement custom renderers

**Rate yourself 1–5:** 5

**How do you customize the appearance of a JList row?**

Use `setCellRenderer()` with a `DefaultListCellRenderer` subclass that overrides `getListCellRendererComponent()`. For `JTable`, use `setCellRenderer()` on a specific `ColumnModel` column with a `DefaultTableCellRenderer` subclass.

**Rate yourself 1–5:** 5

**List the four most common JOptionPane methods:**

1. `JOptionPane.showMessageDialog(...)` — Shows an information/alert message
2. `JOptionPane.showConfirmDialog(...)` — Asks a Yes/No/Cancel confirmation question
3. `JOptionPane.showInputDialog(...)` — Prompts the user for text input
4. `JOptionPane.showOptionDialog(...)` — Displays a customizable dialog with custom button options
