## Self-check questions

### 1. What is the difference between an event source and an event listener?

An event source is the component that generates an event, such as a button, keyboard or sensor. An event listener is the component that waits for and receives that event so that the program can respond to it.

### 2. Can one event source have multiple listeners? Give an example.

Yes. One event source can have more than one listener. For example, when a user clicks a submit button, one listener could validate the form while another listener records the submission.

### 3. Can one listener handle events from multiple sources? Give an example.

Yes. One listener can be registered with multiple event sources. For example, a single ActionListener in a Java Swing application can handle clicks from several buttons and use the event source to determine which button was clicked.

## Conclusion

Event-driven systems respond to events generated by users, timers or sensors. The source generates the event, a listener receives it, and the handler performs the required action.
