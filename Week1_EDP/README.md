
# Week 1 - Event-Driven Programming
My journey learning Event-Driven Programming in Java - Week 1 Activities.

This project contains the completed practical activities for Week 1 of Event-Driven Programming.

## Folder guide

- `Activity1` - Real-world EDP components and self-check answers.
- `Activity2` - Event-loop simulation answers and reflection.
- `Activity3` - Procedural and event-driven Java calculators and comparison.
- `Activity4` - Four corrected Java Swing event-handler examples and bug documentation.
- `Activity5` - AfyaTrack system design and Java Swing prototype.
- `Activity6` - Self-assessment answers and one-page learning summary.

## Requirements

- Java Development Kit (JDK) installed.
- A Java IDE or a terminal/command prompt.

## Compile and run

Open a terminal in the folder containing the Java file.

Example for AfyaTrack:

```bash
javac AfyaTrack.java
java AfyaTrack
```

Example for the event-driven calculator:

```bash
javac EventDrivenCalculator.java
java EventDrivenCalculator
```

Compile and run each Java file separately. The Java file name must match its public class name.
